01 — CONCEPTOS BÁSICOS

¿Cómo funciona el cálculo?

Para conocer la superficie de un terreno rectangular, necesitamos identificar dos medidas y multiplicarlas.

01

Entrada de datos

Obtener el largo y el ancho del terreno en la misma unidad de medida.

02

Procesamiento

Multiplicar el largo por el ancho para obtener la superficie.

03

Salida de datos

Mostrar el resultado en unidades cuadradas, por ejemplo, metros cuadrados.

LA FÓRMULA

Una operación sencilla

El área representa la superficie que ocupa el terreno.

A = L × W
